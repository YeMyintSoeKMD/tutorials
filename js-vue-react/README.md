# Js vs Vue vs React

This repository contains three simple applications that demonstrate the same functionality using different JavaScript frameworks:

1. **Vanilla JavaScript** - Pure JavaScript without any framework
2. **Vue.js** - Using the Vue.js framework
3. **React** - Using the React framework

Each application has the same basic functionality:
- Display a title with a name
- Change the name when a button is clicked
- Show/hide the title when another button is clicked
- Inline css, internal css and external css
